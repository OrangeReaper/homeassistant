# Overview

Welcome to my personal [Home Assistant](https://home-assistant.io) configurations. 

All the automations included in this repository are working with Hass.io (Home Assistant 2026.6.3) and are provided for information and guidance and with no guarantees; 

In my case, Home assistant runs on a MINIX Z100-0dB Fanless Mini PC with a Z-Wave USB Adapter (Aeon Labs Z‐Stick Gen5) to allow the PC to act as a Z-Wave Hub.
